# 🕯️ The Descent

A branching horror text adventure game built with Python and Streamlit.

## 🎮 Play

[Play The Descent online](https://thedescent.streamlit.app/)

## 📖 About

You receive an invitation from your missing grandfather after a year
without hearing from him.

Something is very wrong with the house.

Explore, make choices, discover clues, and try to survive.

There are multiple endings, including several ways to die.

## ✨ Features

- Branching story
- Multiple endings
- Item/inventory choices
- Hidden information that changes available choices
- Randomized elements
- Custom horror-themed UI
- Playable in the browser

## 🛠️ Built With

- Python
- Streamlit
